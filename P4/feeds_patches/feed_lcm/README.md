# feed_lcm
This directory contains patches for the 'lcm' feed.

## Purpose
Patches in this folder are used to modify, enhance or fix issues in the 'lcm' feed components during integration or development.

### Guidelines
- Place all patches specific to 'feed_lcm' here.
- Follow naming convention: '0001-description.patch', '0002-description.patch', etc.
- Ensure patches apply cleanly on top of the feed.
